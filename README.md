

# Git Lab Project

A small Python calculator developed to
practise version control using Git and GitHub.

## Features
- Addition
- Subtraction
- Multiplication

## Installation

Clone the repository:

    git clone https://github.com/shujaehaidar/lab08-git-workshop.git

Enter the project folder:

    cd lab08-git-workshop

## Usage

Run the calculator:

    python calc.py

## Technologies
- Python 3
- Git
- GitHub
